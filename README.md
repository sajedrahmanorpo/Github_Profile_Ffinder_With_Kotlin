GitHub Profile Finder CLI (Kotlin)

A lightweight Command-Line Interface (CLI) application built with **Pure Kotlin** that fetches real-time public GitHub user profiles using the official GitHub REST API.

-- Features
* Real-Time Data Extraction: Fetches name, bio, public repos, followers, and profile link.
* Zero Third-Party Dependencies: Built strictly using Kotlin standard libraries.
* Error Handling: Gracefully handles invalid usernames and HTTP errors.

-- Tech Stack
* Language: Kotlin
* API: GitHub REST API
* IDE: IntelliJ IDEA

-- Output Sample
```text
Enter GitHub Username: sajedrahmanorpo

Bio: CSE Student
Public Repos: 12
Followers: 5
Following: 8
Profile Link: [https://github.com/sajedrahmanorpo](https://github.com/sajedrahmanorpo)
